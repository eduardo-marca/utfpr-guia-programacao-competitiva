# Teorema de Sprague-Grundy

O terema de Sprague-Grundy é um resultado fundamental na teoria de jogos combinatórios, que todo jogo imparcial pode ser representado como um jogo de Nim. O objetivo é achar para um estado de jogo qualquer, um estado correspondente de um jogo de Nim, de forma que os dois estados sejam equivalentes em termos de estratégia vencedora.

A idea é calcular para cada estado do jogo, um número chamado de *Gundy Number* (número de Grundy) que corresponde ao tamanho de uma pilha de Nim equivalente.
